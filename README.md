Django 5.2-платформа для студентов и учебных заведений. Это демонстрационный макет без реальной обработки платежей и персональных данных.

## Запуск

1. Установите зависимости: `python -m pip install -r requirements.txt`.
2. Создайте базу: `python manage.py migrate`.
3. Создайте администратора: `python manage.py createsuperuser`.
4. Запустите сервер: `python manage.py runserver`.

##Основные URL

- `/` — главная страница;
- `/accounts/register/` — регистрация;
- `/accounts/login/` — вход;
- `/institutions/` — поиск заведений;
- `/applications/submit/` — подача заявки;
- `/admin/` — админка Django.

## Проверка

`python manage.py test`

База данных SQLite используется только для локальной демонстрации.
